# Contributing

Thank you for your interest in improving Kings Laucher.

## Current contribution scope

The application source code is not currently published on the main branch. Until source files are made available, useful contributions are limited to documentation, clear issue reports, and project-page improvements.

## Before making a change

1. Search existing issues to avoid duplicate reports.
2. For a significant change, open an issue first to discuss the proposal.
3. Keep changes focused and explain why they are needed.
4. Do not include personal data, credentials, copyrighted assets you do not have permission to share, or modified executable builds.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] Documentation matches the currently published release.
- [ ] Links and Markdown render correctly.
- [ ] No unsupported compatibility, security, or feature claims were added.
- [ ] No secrets or personal information are included.

By contributing, you agree that your contribution may be publicly displayed in this repository. No separate contributor agreement is currently provided.
