## About Kings Laucher

Kings Laucher is an independent launcher project built around a collection of Roblox-related desktop utilities. The v1.0.0 release notes describe a customizable interface and tools for configuring Fast Flags, finding games, and capturing gameplay moments.

This project is **not affiliated with, endorsed by, or sponsored by Roblox Corporation**.

## What’s included

| Feature | Description |
| --- | --- |
| Fast Flag tools | A workflow for applying and managing Fast Flag settings. |
| Automatic configuration | Fast Flag settings selected with the user's computer in mind, as described in the v1.0.0 release notes. |
| Game discovery | A game search experience intended to make finding experiences easier. |
| Screen recording | A built-in way to record gameplay. |
| 30-second moment saver | Save a recent gameplay moment using a configurable key, as described in the release notes. |
| Customization | Adjust parts of the launcher experience. |

Feature descriptions summarize the v1.0.0 release notes. They are not a third-party security audit or a guarantee that every feature works on every system.
