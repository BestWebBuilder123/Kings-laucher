# Security Policy

Kings Laucher is an independent project. Security reports are taken seriously, but this repository does not currently claim that the application has undergone an independent security audit or that its Windows executable is digitally signed.

## Supported release

The currently published release is [v1.0.0](https://github.com/BestWebBuilder123/Kings-laucher/releases/tag/v1.0.0).

## Reporting a vulnerability

Please check the repository's **Security** tab for a private vulnerability-reporting option. Use that option if it is available.

If private reporting is unavailable, do not publish exploit details, credentials, personal data, or files that could put other people at risk in a public issue. You may open a brief issue asking for a private reporting method without including sensitive technical details.

## Safe download practices

- Download releases only from this repository's official [Releases page](https://github.com/BestWebBuilder123/Kings-laucher/releases).
- Compare the downloaded file's SHA-256 hash with the digest shown on the release page and in the README.
- A matching hash checks file integrity against that published digest; it does not prove the publisher's identity or certify the file as safe.
- Do not disable antivirus, bypass SmartScreen, or ignore operating-system security warnings to run the application.
- Do not share private logs, passwords, access tokens, or personal information in issue reports.

## Scope and limitations

This policy is for security concerns related to this repository and its published release. No response-time guarantee or security certification is implied.
