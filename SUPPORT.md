# Support

Thanks for trying Kings Laucher. These steps help keep support requests clear and useful.

## Before opening an issue

1. Confirm which release you are using.
2. Read the [installation and verification guide](docs/INSTALLATION.md).
3. Search [existing issues](https://github.com/BestWebBuilder123/Kings-laucher/issues) for the same problem.
4. Reproduce the issue once and write down the exact steps and error message.

## What to include

For a bug report, include:
- Kings Laucher version.
- Windows version and system type, if known.
- What you were doing when the problem occurred.
- What you expected to happen.
- What happened instead.
- The full error text, with personal information removed.

## Keep reports safe

Never post passwords, access tokens, private account details, or personal files. Remove your Windows username and private directory names from screenshots and logs. Do not attach modified application binaries.

## Where to ask

Use the repository's [Issues page](https://github.com/BestWebBuilder123/Kings-laucher/issues) for bugs and feature requests. Use the [Security Policy](SECURITY.md) for security-related reports; do not publish sensitive vulnerability details in a public issue.
